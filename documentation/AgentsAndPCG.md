## Agents And Procedural Content Generation
This lays out a blueprint for how procedural content generation works, in context of agentic systems.

This focuses less on making the agent or groups of agents themselves non dangerous, but making it so the layout of the vault allows for rooms to be in relative loose tethering of each other. So that way of any given agent becomes unruly, that particular room can be disconnected from other rooms.

### Starting Point Based On Prime Factorization
Rooms are chosen based on factoring two prime together, then upon exit choosing the next prime after on that particular branch of a tree of prime numbers.

### Vaults Using Matrices
Vaults themselves will be generated using matrices of placeholder ascii text graphics, with the same of the vault chosen based on primes.
